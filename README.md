# Dog No Apply

A playful, bilingual (English / Simplified Chinese) website for planning U.S. graduate school applications. It brings together university rankings, graduate Computer Science rankings, location, and cost estimates, and includes a Kanban board for tracking applications.

The name is a joke from Chinese internet slang meaning "not even a dog would apply". The site helps you work out which schools are actually worth applying to.

## Features

- **Rankings**: U.S. News national university rankings (1984–2027 editions, last 10 years shown by default), U.S. News graduate Computer Science ranks, and CSRankings by research area (overall, 4 categories, 27 areas).
- **Filters**: state, city, popular city area, major metro vs. college town, public/private, rank range, CSRankings area, tuition cap, and living-cost cap.
- **Costs**: graduate tuition and fees (in-state or out-of-state/international), living costs, and books for one academic year. The Chinese UI shows CNY at an adjustable exchange rate (default 6.7).
- **Map**: every school on a U.S. map, with the same filters.
- **My Schools**: a Kanban board and table for tracking each school through Considering → Applying → Submitted → Interviewing → Admitted / Rejected / Waitlisted. Schools can be added one at a time or in bulk from the Rankings page. Data is stored in the visitor's browser only.
- **Bilingual**: English by default, with a one-click switch to Simplified Chinese.

## Running locally

There is no build step. Open `index.html` in a browser, or serve the folder with any static file server.

The map page loads Leaflet from unpkg.com, so it needs an internet connection. Everything else works offline.

## Deploying

The site is plain static files and can be hosted on any static host. For GitHub Pages: push the repository to GitHub, then go to **Settings → Pages**, choose **Deploy from a branch**, and select `main` / `(root)`.

## Data sources

- **National university rankings**: U.S. News & World Report, 1984–2027 editions (the spreadsheet above).
- **Graduate Computer Science rankings**: U.S. News Best Graduate Schools, 2026 edition.
- **CSRankings**: computed from [CSRankings](https://csrankings.org/#/index?all&us) public data (see below).
- **City, public/private status, website, coordinates, metro area**: U.S. Department of Education IPEDS institutional directory (HD2024).
- **Metro populations**: U.S. Census Bureau metro-area population estimates (2024).
- **Costs**: IPEDS institutional charges (IC2023_AY, academic year 2023–24).

A school counts as a **major metro** when its metro area has 1 million or more people and the campus is in a city or large suburb (see `MAJOR_METRO_POP` in `scripts/build_data.py`). Everything else counts as a college town or smaller city.

**Popular cities** are defined in `data/sources/hubs.json`. Each one covers one or more whole metro areas, so nearby suburbs are included. For example, San Francisco Bay Area means the San Francisco–Oakland and San Jose metro areas.

**Costs** are the school's average full-time graduate tuition plus required fees, plus the school's own estimate of off-campus food, housing and other expenses for one academic year (about 9 months), plus books. Schools that only report on-campus living costs use those instead. Individual programs can cost more than the average.

## Rebuilding the data

```sh
curl -O https://nces.ed.gov/ipeds/datacenter/data/HD2024.zip && unzip HD2024.zip
curl -O https://www2.census.gov/programs-surveys/popest/datasets/2020-2024/metro/totals/cbsa-est2024-alldata.csv
curl -O https://nces.ed.gov/ipeds/datacenter/data/IC2023_AY.zip && unzip IC2023_AY.zip
python3 scripts/build_data.py US-News-National-University-Rankings-Top-150-Through-2027.xlsx \
    HD2024.csv cbsa-est2024-alldata.csv ic2023_ay.csv
```

Schools are matched to IPEDS by IPEDS ID. Graduate subject ranks are matched by school name and state. When a school is named differently in two lists, add it to `NAME_ALIASES` in the script. CSRankings institutions are matched by website domain, with exceptions in `CSR_OVERRIDES`.

When IPEDS publishes a newer charges file (`IC20xx_AY`), download it and update `COST_YEAR` in the script.

### CSRankings

`scripts/build_csrankings.py` recomputes CSRankings from its public data using the site's own method (all areas, U.S. institutions, last 10 years). The output was checked against the live site and matches exactly for the overall ranking, every category, and sampled areas. Refresh it before rebuilding the site data:

```sh
curl -O https://raw.githubusercontent.com/emeryberger/CSrankings/gh-pages/generated-author-info.csv
curl -O https://raw.githubusercontent.com/emeryberger/CSrankings/gh-pages/institutions.csv
python3 scripts/build_csrankings.py generated-author-info.csv institutions.csv
```
