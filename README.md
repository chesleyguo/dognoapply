# Dog No Apply · 狗都不申

A static website for exploring US News national university rankings (location, public/private, rank history from 1984 to 2027, graduate CS and biological sciences ranks) and tracking applications on a Kanban board.

## 使用

No build step is needed. Open `index.html` in a browser, or host the folder as-is (for example on GitHub Pages). The map page loads Leaflet from unpkg.com, so it needs an internet connection; everything else works offline.

## 文件

- `index.html` (home), `rankings.html`, `map.html` (大学地图), `library.html` (选校库 board/table), `about.html`: the pages
- `css/style.css`: all styles; the color tokens at the top re-theme the whole site
- `js/layout.js`: shared top nav and footer. To add a feature page, add one entry to `NAV`
- `js/i18n.js`: all UI text in English (default) and Simplified Chinese. Static HTML uses `data-i18n` keys; scripts call `I18N.t(key)`. To add or change wording, edit the dictionary there
- `js/common.js`: shared helpers (school detail popup, 选校库 storage and statuses, state names)
- `js/home.js`, `js/rankings.js`, `js/map.js`, `js/library.js`: per-page scripts
- `data/colleges.js`: generated data, do not edit by hand
- `data/sources/clusters.json`: industry cluster definitions (each cluster = a set of metro-area CBSA codes, with English and Chinese names). Edit this to add or change clusters, then rebuild
- `data/sources/grad_cs.csv`: US News Best Graduate Schools Computer Science ranking (2026 edition, collected from usnews.com on 2026-10-19)
- `data/sources/grad_bio.csv`: Biological Sciences ranking, kept but switched off for now (see `SUBJECTS` in `scripts/build_data.py`)
- `data/sources/csrankings_us.json`: CSRankings ranks for US institutions (overall, 4 categories, 27 areas), generated by `scripts/build_csrankings.py`
- `data/us-states.js`: state outlines for the map, generated by `scripts/build_us_map.py` from [us-atlas](https://github.com/topojson/us-atlas)
- `scripts/build_data.py`: rebuilds the data file
- `US-News-National-University-Rankings-Top-150-Through-2027.xlsx`: source rankings

## 更新数据

City, public/private status, website, coordinates and metro area (CBSA) come from the US Department of Education IPEDS directory file; metro populations come from the Census Bureau file. Cost estimates (2023–24 graduate tuition and fees, plus each school's own estimate of off-campus living costs and books for one academic year) come from the IPEDS charges file; when IPEDS publishes a newer `IC20xx_AY` file, update the file and `COST_YEAR` in the script. A school counts as "major metro" when its metro area has 1M+ people and the campus is in a city or large suburb (see `MAJOR_METRO_POP` in the script). The script joins it to the rankings on the IPEDS ID. Subject ranks are joined from `data/sources/` by school name and state; when a school's name differs between the lists, add it to `NAME_ALIASES` in the script.

```sh
curl -O https://nces.ed.gov/ipeds/datacenter/data/HD2024.zip && unzip HD2024.zip
curl -O https://www2.census.gov/programs-surveys/popest/datasets/2020-2024/metro/totals/cbsa-est2024-alldata.csv
curl -O https://nces.ed.gov/ipeds/datacenter/data/IC2023_AY.zip && unzip IC2023_AY.zip
python3 scripts/build_data.py US-News-National-University-Rankings-Top-150-Through-2027.xlsx HD2024.csv cbsa-est2024-alldata.csv ic2023_ay.csv
```

### CSRankings

`scripts/build_csrankings.py` recomputes [CSRankings](https://csrankings.org/#/index?all&us) from its public data with the site's own method (all areas, US, last 10 years); the output was checked against the live site and matches exactly (overall, every category, and sampled areas). Refresh it before rebuilding the site data:

```sh
curl -O https://raw.githubusercontent.com/emeryberger/CSrankings/gh-pages/generated-author-info.csv
curl -O https://raw.githubusercontent.com/emeryberger/CSrankings/gh-pages/institutions.csv
python3 scripts/build_csrankings.py generated-author-info.csv institutions.csv
```
